## 4. 分析记录

### 4.1 定位过程
1. 名字串引用点 `0xb75532` 落在处理块 `0xb75449`..`0xb75627` 内。
2. 容量经「`mov edx,[eax+78h]`（解码缓冲分配器）+ `push IMM; call edx`」在 `B7545B` 确证为 `0x64`。
3. 逐字段按线序读取，类型全部由汇编判定（SOP §6）。
4. 闭合：`B754E9`（SOP §5.3）。
5. 去向：`vt[0x300]` @`B7560B`（2 实参）。

### 4.2 长度闭合与容量口径
- 容量 `0x64` = 100 = `u32(result) + 96`：`ms_set` 由 `sub_B06020` 预留单槽 **0x60=96**，线长由 `sub_B43B00` 整函数展开实算 **95**（跨度 96 ≠ 线长 95）。
- 线长 = `4 + 95` = 99。

### 4.3 结构/数组说明
- `sub_B43B00`（214B）整函数展开：`8 + 2 + 2 + 43(u8 循环 `cmp ecx,2Bh`) + 4×8(8×u64 循环 `cmp esi,4`) + 2×4(u16 循环 `cmp ecx,4`)` = **95**。
- 结构体成员名可用打印器 `sub_B4A7E0` 后续拆分。
