## 与其他命令的关联

- 配对请求：`../CS-0xA380-auth-worldlist_select/`（`0xA380`，声明容量 `0xA`）。
- 同族：`../SC-0x298E-auth-worldlist_get_r/`（`0x298E`，大区列表下发）。
- **auth 协议类的字段写法（本批唯一 auth 样本）**：不使用预留族 `sub_B41470`/`sub_B413B0`/`sub_B05E30`，
  而是用 `ebp` 手工推进缓冲游标（`mov eax,ebp; push eax; add ebp,N; call <读取器>`），
  槽变量（`var_100`/`var_F4`/`var_F8`/`var_104`/`var_F0`）保存「推进前的 ebp」供日志与去向取值。
  ⇒ 判字段时**不要**把 `add ebp,N` 当成预留；`N` 只对定长字段等于线长，对串则是槽位预算。
- 容量口径例证：`容量 0xE7 = 231 = 4 + 49 + 129 + 4 + 4 + 41`（Σ claim，串用槽预算）✓ —— 本批最"干净"的多串样本。
