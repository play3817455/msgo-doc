2. 容量经「`mov edx,[eax+78h]`（解码缓冲分配器）+ `push IMM; call edx`」在 `B2A0B9` 确证为 `0x84`。
3. 逐字段按线序读取，类型全部由汇编判定（SOP §6）。

- `data` 为 `u8[]`（预留 `sub_B05EA0` 槽步进 1、读 `sub_B06230`）；线长 = `4 + n`。
