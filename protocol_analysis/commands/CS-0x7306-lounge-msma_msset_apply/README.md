## 4. 分析记录

### 4.1 定位过程
- 分配器指纹：`mov <reg>,[<obj+0Ch>]` → `mov <reg>,[eax+78h]` → `push <容量>; call <reg>` 取得组包缓冲
  （容量 `push` @ `0xb98cd6`）；`sub_ABB2F0` 初始化 `{cur,end}`，**游标自 `buf+2` 起**，opcode 占 `buf+0..1`。
- opcode：`0xb98d04`（`mov word ptr [...], 0x7306`）。
- 字段名取自**提交（`sub_B02FF0`）之后**的 trace 打印块（`push offset a<Name>; …; call sub_41D990`），
  **日志名序 == 线序**；去向统一为发送槽 `vt[0x58](buf, 负载长度)`。

### 4.2 长度闭合
- `2 + 2 + 2 = 6 ≤ 容量 0xA = 10`（富余 4）

### 4.3 存疑点
- 两字段均为 u16（写线为 `mov [eax],ax` / `mov [edx],ax`，目标操作数宽度 2）——不得按语义直觉记成 u32。
- `deck_type` 取值域 {0,1}（编成套别下标，实测小集合）；槽查找 `sub_6183B0` 布局 `800*deck_type + 80 + 80*slot` ⇒ 每套 10 槽。
