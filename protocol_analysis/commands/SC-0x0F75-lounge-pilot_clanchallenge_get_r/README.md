## 4. 分析记录

### 4.1 定位过程
1. 名字串引用点 `0xB55608` 落在 `sub_B51930` 的 case 块 `0xB5546D..0xB55853` 内（错误码 `0x76`）。
2. **数组部分**：
   - `0xB5549E..0xB554B2`：`sub_B413F0(out=&var_2C08, &缓冲游标 var_2C2C)` —— 一次 `add [ecx],70h` ⇒ 预留 **112 = 7×16** 字节，**不带线上计数**（固定 7 槽）。
   - `0xB554C0..0xB554DB`：循环 `edi = 0..6`，每次 `sub_B44700(元素地址, &线游标)`，元素地址 `+= 0x10`。
3. **元素读取器整函数扫描**（`sub_B44700`，`0xB44700..0xB44749`）：消费 `u32(4) + u32(4) + u8(1) = 9` 字节 ⇒ **元素线长 9 ≠ 缓冲步进 16**。元素成员名取自元素打印器 `sub_B4BDE0`（`id=`/`val=`/`is_clear=`，内存偏移 `[0]`/`[4]`/`[8]`，与线序一致）。
4. **尾部标量**：5 组「预留 + bounded 读取器」（u8/u16/u8/u8/u8）。
5. 含义取自块内日志串；去向 `vt[0x174]`（6 个实参，见 `asm.md` E6）。

### 4.2 长度闭合
- `7×9 + 1 + 2 + 1 + 1 + 1 = 69`；闭合点 `0xB555C5`/`0xB555CB` 要求「游标 == 末尾」✓
- 容量校验：`118 = 7×16(结构体跨度) + 6` ⇒ **容量 = Σ缓冲 claim**（数组 claim = 元素数 × 结构体跨度）✓，与线长 69 不等是**正常**的（结构体跨度 > 元素线长）。
- 三方对齐（元素线长）：① 元素读取器消费 9（`sub_B44700`）；② 缓冲步进 16（`0xB554D5`）；③ 数组预留 7×16（`sub_B413F0`）。①≠②≠③ 中的 ① 是**线长**，②③ 是**结构体/缓冲**步进 —— 本命令正是「结构体步进 ≠ 元素线长」的样本。
