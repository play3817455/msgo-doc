## 4. 分析记录

### 4.1 定位过程
- `sub_B36EC0` @ `0x00b36ec0`；分配器指纹 `mov <reg>,[<obj+0Ch>]` → `mov <reg>,[eax+78h]` → `push 0x2A; call <reg>` 取得组包缓冲（游标自 `buf+2` 起，opcode 占 `buf+0..1`）。
- 字段名取自**提交（`sub_B02FF0`）之后**的 trace 打印块日志串，**日志名序 == 线序**。

### 4.2 长度闭合
- 2 + 4+2+2+2+4+1+2+1+2+1 = **23** ≤ 容量 `0x2A`=42（富余 19）

- `msec` 记 **u16**、`wrestle_id` 记 **u32** —— 与语义直觉相反，但由写线原语宽度确证（`sub_B02DA0` / `sub_B02D80`）。
