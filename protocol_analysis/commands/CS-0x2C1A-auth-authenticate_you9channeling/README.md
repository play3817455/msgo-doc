## 4. 分析记录

### 4.1 定位过程
- `sub_B055D0` @ `0x00b055d0`；分配器指纹 `mov <reg>,[<obj+0Ch>]` → `mov <reg>,[eax+78h]` → `push 0x146; call <reg>` 取得组包缓冲（游标自 `buf+2` 起，opcode 占 `buf+0..1`）。
- 字段名取自**提交（`sub_B02FF0`）之后**的 trace 打印块日志串，**日志名序 == 线序**。

### 4.2 长度闭合
- 2 + 32 + 33 + 128 + 128 = **323** ≤ 容量 `0x146`=326（富余 3）

### 4.3 存疑点
- 4 个串的槽预算与容量差额（3 字节）未逐一解释；按「容量 ≥ 负载」口径处理，**未把差额当字段**。
