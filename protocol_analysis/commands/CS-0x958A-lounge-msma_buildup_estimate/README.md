## 4. 分析记录

### 4.1 定位过程
- 分配器指纹：`mov <reg>,[<obj+0Ch>]` → `mov <reg>,[eax+78h]` → `push <容量>; call <reg>` 取得组包缓冲
  （容量 `push` @ `0xb96596`）；`sub_ABB2F0` 初始化 `{cur,end}`，**游标自 `buf+2` 起**，opcode 占 `buf+0..1`。
- opcode：`0xb965cc`（`mov word ptr [...], 0x958A`）。
- 字段名取自**提交（`sub_B02FF0`）之后**的 trace 打印块（`push offset a<Name>; …; call sub_41D990`），
  **日志名序 == 线序**；去向统一为发送槽 `vt[0x58](buf, 负载长度)`。

### 4.2 长度闭合
- `2 + 8(u64) + 4 + 2 + 2 = 18 ≤ 容量 0x16 = 22`（富余 4）

- `usenum` / `param_idx` 均为 **u16**（写线原语 `sub_B02DA0`），不得按批次-17 的 `0x5FAB` 直觉套用（该条同为 u16，互证一致）。
