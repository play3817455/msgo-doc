## 2. 反例 / 易错点（★本批重点）

- **两个 NUL 串的「槽」与「线长」不同**：`pilot_name` 槽预算 `0x19 = 25`、`msg` 槽预算 `0xB5 = 181`，但线上各只消费 `串长 + 1`。容量核算 `0xDB = 219 = 10 + 25 + 181 + 3` **必须按槽预算**；若按实际串长算则容量对不上。
- 串缓冲的两个起点由 `add edi,19h`（`0xB0F872`）/`add edi,0B5h`（`0xB0F891`）推进，**这是缓冲内偏移、不是线游标**；线游标只由 `sub_B02BA0` 与 bounded 读原语推进。
- 机器草案（`draft-wire.md`）本次**字段数与人工一致（9 个）**，但在两个串之后仍正确续扫了 3 个 u8；草案把串的偏移写成 `?` 是正常的（变长）。
- 与批次-4 的 `i8` 口径差异：批次-4 对「预留槽 + bounded u8 + 打印器 `movsx`」记 `i8`；本条派发侧明确 `movzx` ⇒ 记 `u8`（语义以使用侧为准），已在 §1 记录。
