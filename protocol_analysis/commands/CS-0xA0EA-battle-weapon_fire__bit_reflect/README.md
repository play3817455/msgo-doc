## 4. 分析记录

### 4.1 定位过程
- 分配器指纹：`mov <reg>,[<obj+0Ch>]` → `mov <reg>,[eax+78h]` → `push <容量>; call <reg>` 取得组包缓冲
  （容量申请 `push 0x002E` @ `0xB3B396`）。
- 写线游标：`sub_ABB2F0` 初始化 `{cur,end}`，**游标自 `buf+2` 起**，opcode 占 `buf+0..1`。
- opcode：`0xB3B3CC`（`mov     word ptr [ebp+0], 0A0EAh`）。
- 字段名取自**提交（`sub_B02FF0`）之后**的 trace 打印块（`push offset a<Name>; …`），**日志名序 == 线序**。
- 发送去向统一为 `vt[0x58](buf, 负载长度)`（`sub <len>,<buf首址>` = 游标 − 缓冲首址）。

### 4.2 长度闭合
- `2 + 4 + 4 + 3×2 + 3×2 + 1 + 2 + 2 = 27 ≤ 容量 0x2E = 46`（富余 19）

### 4.3 存疑点
- 坐标全为 **u16**（写线原语 `sub_B02DA0`），不得按语义直觉改成 u32。
- `charge_lv` 打印器 `sub_B0C1F0`（`movsx`）；线宽 1 字节记 `u8`。
- 容量 46 与负载 27 有 19 字节富余。
