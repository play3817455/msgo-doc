## 4. 分析记录

### 4.1 定位过程
1. 名字串引用点 `0xB571C4` 落在处理块 `0xB56F00..0xB574F1`。
2. 容量经「`mov edx,[eax+78h]`（分配器）+ `push IMM; call edx`」在 `0xB56F1C` 确证为 `0x2BDC`。
3. 逐字段按线序读取（读取器原语 / 内联读取器 / 复合读取器），字段类型由汇编判定（SOP §6）。
4. 闭合：`0xB5717B`。
5. 去向：`vt[0x4B0]` @ `0xB5749B`（11 实参）。

### 4.2 长度闭合
- 4+10+8+4+4+4 + 100×108 + 4 + 3×108 + 65 + 1 = **11228**（== 容量 `0x2BDC`）
- 闭合点 `0xB5717B` 要求「游标 == 报文末尾」✓
- 记账口径说明：两个数组按 **槽步进 108**（不是元素线长 99）进闭合算式——循环体
  `0xB57088` / `0xB57106` 是 `add [游标], 6Ch`，即游标每次推进 `0x6C`，元素线长 99 由读取器
  `sub_B46690` 内部消费（见 §2 的 2026-09-26 订正）。三者（读取器消费量 99 / 槽步进 108 /
  循环步进 0x6C）在改记 99 之后**不再互相矛盾**。
