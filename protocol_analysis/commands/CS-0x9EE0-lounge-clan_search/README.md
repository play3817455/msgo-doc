## 4. 分析记录

### 4.1 定位过程
- 分配器指纹：`mov <reg>,[<obj+0Ch>]` → `mov <reg>,[eax+78h]` → `push <容量>; call <reg>` 取得组包缓冲
  （容量申请 `push 0x002A` @ `0xBA1646`）。
- 写线游标：`sub_ABB2F0` 初始化 `{cur,end}`，**游标自 `buf+2` 起**，opcode 占 `buf+0..1`。
- opcode：`0xBA1683`（`mov     word ptr [ebp+0], 9EE0h`）。
- 字段名取自**提交（`sub_B02FF0`）之后**的 trace 打印块（`push offset a<Name>; …`），**日志名序 == 线序**。
- 发送去向统一为 `vt[0x58](buf, 负载长度)`（`sub <len>,<buf首址>` = 游标 − 缓冲首址）。

### 4.2 长度闭合
- `2 + 31(串槽) + 1 + 1 = 35 ≤ 容量 0x2A = 42`（富余 7）

### 4.3 存疑点
- 串后字段偏移浮动（串长可变）⇒ 偏移列记 `var`，不编造具体偏移。
- `clan_kind`/`search_kind` 打印器 `sub_B0C1F0`（`movsx`）；线宽 1 字节，顶层记 `u8`。
- 容量 42 与负载上限 35 有 7 字节富余。
