## 4. 分析记录

### 4.1 定位过程
- 分配器指纹：`mov <reg>,[<obj+0Ch>]` → `mov <reg>,[eax+78h]` → `push <容量>; call <reg>` 取得组包缓冲
  （容量申请 `push 0x00DA` @ `0xB34976`）。
- 写线游标：`sub_ABB2F0` 初始化 `{cur,end}`，**游标自 `buf+2` 起**，opcode 占 `buf+0..1`。
- opcode：`0xB349B2`（`mov     word ptr [ebp+0], 9F0Dh`）。
- 字段名取自**提交（`sub_B02FF0`）之后**的 trace 打印块（`push offset a<Name>; …`），**日志名序 == 线序**。
- 发送去向统一为 `vt[0x58](buf, 负载长度)`（`sub <len>,<buf首址>` = 游标 − 缓冲首址）。

### 4.2 长度闭合
- `2 + 4 + 2 + 4 + 4 + 1 + 1 + 181(串槽) + 1 + 1 = 201 ≤ 容量 0xDA = 218`（富余 17）

### 4.3 存疑点
- 串后字段偏移浮动 ⇒ 记 `var`。
- 四个 1 字节标志字段的打印器为 `sub_B0C1F0`（`movsx`）；线宽由写线原语 `sub_B061C0` 确证为 1 字节，顶层记 `u8`。
- 容量 0xDA=218 与负载上限 201 有 17 字节富余（串槽按上限计）。
