## 4. 分析记录

### 4.1 定位过程
- `sub_BA54D0` @ `0x00ba54d0`；分配器指纹 `mov <reg>,[<obj+0Ch>]` → `mov <reg>,[eax+78h]` → `push 0x2336; call <reg>` 取得组包缓冲（游标自 `buf+2` 起，opcode 占 `buf+0..1`）。
- 字段名取自**提交（`sub_B02FF0`）之后**的 trace 打印块日志串，**日志名序 == 线序**。

### 4.2 长度闭合
- 2 + 4 + 4 + 8192 + 811 = **9013** ≤ 容量 `0x2336`=9014（上限场景，`buffer_size` ≤ 0x2000）

### 4.3 存疑点
- ★ 变长段：`buffer_size`(u32，上限 0x2000) + `buffer[]`（逐字节内联拷贝）。
