## 4. 分析记录

### 4.1 定位过程
- 分配器指纹：`mov <reg>,[<obj+0Ch>]` → `mov <reg>,[eax+78h]` → `push <容量>; call <reg>` 取得组包缓冲
  （容量申请 `push 0x000E` @ `0xBA0726`）。
- 写线游标：`sub_ABB2F0` 初始化 `{cur,end}`，**游标自 `buf+2` 起**，opcode 占 `buf+0..1`。
- opcode：`0xBA075C`（`mov     word ptr [ebp+0], 979Ch`）。
- 字段名取自**提交（`sub_B02FF0`）之后**的 trace 打印块（`push offset a<Name>; …`），**日志名序 == 线序**。
- 发送去向统一为 `vt[0x58](buf, 负载长度)`（`sub <len>,<buf首址>` = 游标 − 缓冲首址）。

### 4.2 长度闭合
- `2 + 1 + 1 + 1 = 5 ≤ 容量 0xE = 14`（富余 9）

### 4.3 存疑点
- 三个 1 字节字段的打印器为 `sub_B0C1F0`（`movsx`，符号扩展打印）；**线宽由写线操作数宽度确证为 1 字节**，顶层字段按口径记 `u8`。
- 容量 0xE=14 明显大于负载 5（富余 9），属调用方预留；已在 `notes.md` 记录差值。
