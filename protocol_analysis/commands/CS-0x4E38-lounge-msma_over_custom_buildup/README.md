## 4. 分析记录

### 4.1 定位过程
- 分配器指纹：`mov <reg>,[<obj+0Ch>]` → `mov <reg>,[eax+78h]` → `push <容量>; call <reg>` 取得组包缓冲（游标自 `buf+2` 起，opcode 占 `buf+0..1`）。
- 字段名取自**提交（`sub_B02FF0`）之后**的 trace 打印块（`push offset a<Name>; …; call sub_41D990`），**日志名序 == 线序**。

### 4.2 长度闭合
- 2 + 8 + 42 = 52 ≤ 容量 0x36=54（富余 2）

### 4.3 存疑点
- 日志名序（`uniq_msid=`→`buildup_info=`）与线序一致。
- `buildup_info` 由复合写入器 `sub_B41DA0`（`0xB41DA0..0xB41DF7`）写成 **42** 字节 = 7×u16(源偏移 0..13) + 7×u32(源偏移 0x10..0x2B)；源结构跨度 **44** 字节 ≠ 线长 42（第 2 段源起点 `esi+0x10`，源首段占 14 字节）。
- 未决：`buildup_info` 14 个成员的**语义名**未逐一取证（线长/偏移已由写入器函数体确证）。
