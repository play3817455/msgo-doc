## 4. 分析记录

### 4.1 定位过程
1. 名字符串 `0xEE9E58` 的引用点 `0xB54A34` 落在 `sub_B51930` 的 case 块 `0xB54919..0xB54B4C` 内（错误码 `0x247`）。

3. 字段 2 是**数组**：`0xB549A0 call sub_B41690`（定长数组预留，`0xB416B0 add [edx],8` ⇒ 槽步进 **8** 字节），返回 `{基址, N}` 于 `var_2C18`。
