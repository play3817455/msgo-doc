### 4.2 长度闭合与容量口径
- `sub_B06140` @`B24A2F` / @`B24A78` 各一次推进游标 `0x70`(=112) ⇒ 每块 claim = 112 = 14（`cmp edi,0Eh` @`B24A58`）× 8（槽步进 `add ebx,8` @`B24A55`）。

- 元素由 `sub_B07E70` 读：`u32 + u8 + u8` = **6B** ⇒ 线长 = 2 × 14 × 6 = 168。
