### 4.1 定位过程
1. 名字符串 `0xEE9F34` 的引用点 `0xB53F45` 落在 `sub_B51930` 的 case 块 `0xB53E24..0xB5405D` 内（块首 `push 203h`，全部错误路径 `0xB53E80`/`0xB53EEB`/`0xB53F07` 一致用 `0x203`）。

3. 字段 2 是**数组**：`0xB53EA8 call sub_B41850`（`sub_B41850` 为「定长数组预留」，`0xB41870 add [edx],4` ⇒ 槽步进 **4** 字节），返回 `{基址, N}` 于 `var_2C18`；随后循环 `N` 次、每次 `0xB53ECA call sub_B02DD0` 读一个 u32 进元素、`0xB53ED6 add [var_2C48],4` 推进元素指针。
4. 字段 2 元素线长 **4**（= 循环内 bounded 读取器 `sub_B02DD0` 的消费量，与预留槽步进一致）。
5. 日志顺序（`restrictitem_buy={` → 元素逗号列表）与线序一致。
