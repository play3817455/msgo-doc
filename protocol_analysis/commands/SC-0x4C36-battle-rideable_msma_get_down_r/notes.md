## 追加 2：实参 ↔ 报文字段 ↔ 落点实体 已逐字节钉死（2026-09-30）

### 2.1 实参序 = 线序（1:1），且身份槽在 `to_` 侧

`vt[0x318]` @ `0xB166C2` 的 `push` 序与日志标签（`result`@`0xB16336`、`access_type`@`0xB16376`、
`from_ent_id`@`0xB1639A`、`to_world_id`@`0xB163BE`、`to_pilot_id`@`0xB163E6`、`to_ent_id`@`0xB1640E`、
`hp_now`@`0xB16436`、`hp_max`@`0xB1645E`）逐格同序 ⇒

```
sub_BAA950(a1..a8) = sub_AFCA40(a1..a8)
  = (result, access_type, from_ent_id, to_world_id, to_pilot_id, to_ent_id, hp_now, hp_max)
```

`sub_AFCA40` 逐条核过（`0xAFCA40..0xAFCA7D`）：`to_world_id`/`to_pilot_id` 送
`sub_44FC00`（`ecx = dword_11E3EA8`）→ **返回 `to_` 实体的指针**，作为 `sub_4BEF70` 的第 4 实参；
`this = dword_11E3F94`（战斗管理单例，`0xAFCA7B mov ecx, esi`）。

`sub_4BEF70` 的分派（`0x4BEF4B` 起逐条核过）：

| `access_type` | 落点 | 形参实值 |
|---|---|---|
| `11` | `sub_4BA4E0`（`retn 14h`） | `this=战斗管理单例`、`a2=from_ent_id`、`a3=to_实体指针`（`edi`，在 `sub_4B5A30` 改写该槽**之前**就已缓存 ⇒ 是原指针）、`a4=to_ent_id`、`a5=hp_now`、`a6=hp_max` |
| `12` | `sub_4BE190` | 同上（`a2=from_ent_id`、`a3=to_实体指针`…） |

### 2.2 `+0x440` bit0 的落点（本命令**按分支换边**）

`sub_4BA4E0`：`v7 = a3`（**`to_` 实体指针**，闸门读 `v7[9]`/`v7[10]`）、
`v8 = sub_4B59B0(this, &a3, (char)a2)`（**`from_ent_id`** 那具）、
`v10 = sub_4B59B0(this, &a2, SLOBYTE(a4))`（**`to_ent_id`** 那具）：

| 分支 | 闸门 = 「`to_`（带 `to_world`/`to_pilot` 身份槽的一侧）是本地玩家自己」 | bit0 写 |
|---|---|---|
| `access_type==11` 闸门成立 | 成立 | `*(*v8+1088) \|= 1`（置 **`from_ent`** 侧）+ `*(*v8+12)=2`；随后 `*(*v10+1088) &= ~1`（解 **`to_ent`** 侧） |
| `access_type==11` 闸门不成立 | 不成立 | `*(*v10+1088) \|= 1`（置 **`to_ent`** 侧）+ `sub_478F40(v7[9], v7[10])` |
| `access_type==12` | — | **完全不碰 bit0**；只 `*(ent+1960) = 0`（落在 `from_ent_id` 那具上，`0x4BE389`）+ `*(*v8+12)=3` |

★与 `SC-0x1B32` 的差别要说清：**两命令的身份槽不在同一侧**（`0x1B32` 在 `from_`、本条在 `to_`），
所以「置位侧 = 带身份槽的一侧」这条**只对 `0x1B32/11` 成立**；本条 `11` 半是**按闸门换边**的。

### 2.3 `+0x7A8`（= `ent+1960`）这一字节：已找到第二个读者（C3 闭）

`ent+0x7A8` 是**单字节フラグ**（同处随后是 `+0x7AC..+0x7B4` 三个 dword，构造器 `sub_49C470@0x49CC60`
按「byte, dword×3, byte, dword…」清零 ⇒ 不是别处的 4×float 块，**别名的只是偏移值**）：

- 写入：本条 `12` 半 `*(ent+1960) = 0`（`0x4BE389`）；`0x1B32` `12` 半 `*(ent+1960) = 1`（`0x4BDEE6`）
  ⇒ **一置一清的一对**；
- **读者**：`sub_4AA6B0@0x4AA961`（`cmp byte ptr [edi+7A8h], 0`）与
  `sub_4AA6B0` 的另一处 `[edi+7A0h]` —— 该函数在 `if (*((_BYTE*)v3 + 1960))` 分支里
  **遍历 `+0x7A0` 那条链表并逐个把子实体的包围盒并进自己**（`sub_4AA6B0(子, …)` 后取 min/max）。
- ⇒ 语义定界为**「子を抱えている（搭乗者を持つ）側のフラグ」**：`+0x7A0` = 子リスト、
  `+1960` = 「子を持つ」、`+0x7A8` = 同族の単バイトフラグ。**不是**「降りた側の後処理フラグ」。
