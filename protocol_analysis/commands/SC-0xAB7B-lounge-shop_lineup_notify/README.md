## 4. 分析记录

### 4.1 定位过程
1. 名字串引用点 `0xb71a91` 落在处理块 `0xb718ec`..`0xb71c70` 内。
2. 容量经「`mov edx,[eax+78h]`（解码缓冲分配器）+ `push IMM; call edx`」在 `B71905` 确证为 `0x30DC`。
3. 逐字段按线序读取，类型全部由汇编判定（SOP §6）。
4. 闭合：`B71A48`（SOP §5.3）。
5. 去向：`vt[0x3B0]` @`B71C15`（4 实参）。

### 4.2 长度闭合与容量口径
- 容量 `0x30DC` = 12508 = `u32(id_type_num) + 500×1(id_type 槽) + u32(item_num) + 500×24(item_list 槽)`；两处上限均为 `cmp ebx,1F4h`@`B71964`/`B719E8`。
- `id_type` 为 `u8[]`（预留 `sub_B05EA0` 槽步进 1、读 `sub_B06230`）；`item_list` 元素**线长 23 / 槽步进 0x18=24**（`sub_B416C0` 预留 + `sub_B458A0` 消费）。
- 线长 = `4 + n₁ + 4 + 23·n₂`。
