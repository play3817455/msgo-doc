服务端配置表 srv.*

这些表既不是客户端 datafile 的投影（那是 cfg.*，由 cfgload 按 CSV 动态建表），也不是每机师持久化（那是 game.*，行键含 world_id/pilot_id）：它们是全服唯一的服务端策略参数 / 大区内容。

运行时来源就是这些表本身——db_design 的 JSON 只当文档（HTML 站点输入）。缺省值与降级在 internal/lounge/srv_config.go（loadSrv*，表没播种/读库失败时用缺省值 + 告警，不断链）。按请求读表 ⇒ 改表即热更。

每列的协议证据 VA 写在迁移 SQL 的 COMMENT 里，本页正文即由迁移反推（扫 serverv/migrations/ 下所有含 CREATE TABLE srv. 的文件；每张表标出自己的迁移文件名，不写死版本号，免得新表静默漏进文档站）。

本页 JSON 由 db_design/tools/build_srv_docs.py 从 ['serverv/migrations/0012_srv_config.up.sql', 'serverv/migrations/0013_srv_lobby.up.sql', 'serverv/migrations/0018_srv_shop_lineup.up.sql', 'serverv/migrations/0024_deckcost_extend.up.sql', 'serverv/migrations/0027_chargepoint_url.up.sql', 'serverv/migrations/0030_xwar_booking_and_forcegauge.up.sql', 'serverv/migrations/0033_srv_shop_recycle_and_itemcode.up.sql', 'serverv/migrations/0035_srv_itembox_drop.up.sql'] 反推生成（只当文档）；运行时来源是库里的这些表。
