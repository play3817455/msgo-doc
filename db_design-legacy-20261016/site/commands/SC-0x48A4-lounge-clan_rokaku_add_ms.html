订正理由
`ms[]` 的草稿行有两处错：① 线类型写成 `array<ms>`，元素名撞上了 battle 线形的 `ms`（244B）；实际元素由 `sub_B43A80` 读，整函数消费 `sub_B43570`(303) + 3×`sub_B439D0`(30) + 2×u32(8) = **401B**，成员落 `schema/composites/ms_rokaku.json`（打印器 `sub_B4A6D0` 打 `body=` / `weapons={` / `limit_use=` / `limit_coolup=`）。② 长度列只写了元素线宽 `401`（条数另有线上字段 `ms_count`），按 §3.1 应为 `401·ms_count ≈ 4+401·ms_count+4`；草稿的「总长 69896」与 `is_firstonetime` 偏移 `69892` 都是**容量/内存记账**（`4+168×416+4`，槽 0x1A0=416），不是线偏移 —— 线偏移只能是 `var`。元素线长 401 ≠ 槽 416（内存里 3 个 weapons 槽各 32B，线上各 30B），两者必须分开记。

这些字段的口径由 IDA 汇编逐条核对后人工订正，不再等同 fields.csv 原值 （覆盖行带 override_verified: true）；revision 变号会让旧汇编复核结论作废、 必须重跑 verify_commands_ida.py ingest。
