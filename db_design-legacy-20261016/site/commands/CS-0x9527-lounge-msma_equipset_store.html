fields.csv 把 121B 的 equip_set 摊成 9 行成员（`equip_set.uniq_id` … `equip_set.setname`）却没有父行：站点看不到「这是一个 121B 的结构体」，包结构体里只剩 9 个散字段 —— 与 `CS-0x7916` 的 snapshot 同一形态。补一行父行 `equip_set`（`struct<equip_set>`，121B，偏移 10 = `uniqid_ms` 之后），成员仍由 `composites/equip_set.json` 承载（成员名取自打印器 `sub_B4AA30`）。父行出现后那 9 行被自动识别为成员占位行（`is_member_row`），不再参与线长求和：线长仍是 `8 + 121 = 129`，与 README 的容量等式 `2 + 8 + 121 = 131 ≤ 134` 一致。

这些字段的口径由 IDA 汇编逐条核对后人工订正，不再等同 fields.csv 原值 （覆盖行带 override_verified: true）；revision 变号会让旧汇编复核结论作废、 必须重跑 verify_commands_ida.py ingest。
