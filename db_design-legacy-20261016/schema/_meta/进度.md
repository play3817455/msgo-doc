## 说明

- `table_disposition` / 列 `disposition` 为**启发式初稿**，需人工复核
- 战斗域 struct 默认 `EVENT`（不入库候选）
- 生成器**只补缺、不覆写**已存在的 `composites/`/`tables/`/`entities/`；`cleanup_stale()`
  只删带 `autogen: true` 且未定稿（`proposed/draft/tbd`）的文件
- 别名壳（`layout_same_as` / `prefix_of`）的成员由 `materialize_alias_members.py` **摊平落盘**：
  站点本来也会沿别名展开，但 JSON 层不能是空的（不能只写「见 XXX」）；`--check` 报漂移
- **别名实体（`entities/*.json` 的 `alias_of`）反过来：`fields` 必须留空**（成员只在
  `composites/<id>.json` 一处维护，站点 `build_entity_detail` 对空 `fields` 就地摊平）。
  同一个 `--check` 也量这一条 —— 生成器曾往别名实体里塞占位 blob，让
  `entities/ms_lounge.json` 顶着两个 `TBD` 成员清单（既挡住摊平、又被 `check_meanings.py` 记成「语义名待定」）
- 已声明行键（人工精修，生成器不写此字段）：`tbl_adop_list` / `tbl_buildup_info` / `tbl_equip_set` / `tbl_missionunit_set` / `tbl_ms_rokaku` / `tbl_ms_set` / `tbl_unlocked_navi` / `tbl_unlockw`
