## ★订正（2026-10-05）：col41/col42 不是「奖励」，是「累计门槛」

原表把 col41/col42 记作 `reward_id`（等级达成奖励 ID）/ `bonus_gp`（等级奖励 GP）。三个消费者读的都是
**「累计门槛」语义**，据此把两个名字改掉：

| 消费者 | 证据（反编译） | 结论 |
|---|---|---|
| `sub_69FD90(a1)` | `while(1){ sub_510410(&v6, &(level)); if (v6==end) return -1;`<br>`if ((unsigned)a1 < *(_DWORD*)(v6+64) \|\| v1==18) break; ... }`<br>`return *(unsigned __int8*)(v6+16);` | 拿一个累计值 `a1` 逐级比较 **`row[+48]`**，返回 **`row[+0]`（= col0 等级，u8）** ⇒ `+48` = **该等级的累计门槛** |
| `sub_69FE10(level)` | `v4 = row(level); if (!(level-1)) return *(v4+52);`<br>`v5 = row(level-1); return row(level)[+52] − row(level-1)[+52];` | 对 **`+52`** 取**逐级差分** ⇒ `+52` 是**累计量**（差分 = 本级所需） |
| `sub_69FD20(level, v)` | `... sub_510410(&v6,&(level)); if (v6!=end) return v − v6[17];`（`v6[17]` = 节点 +68 = 行 +52） | 返回 **`v − row[+52]`** ⇒ 同为累计量 |
