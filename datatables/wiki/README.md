## 2. 站上两种格式（都要吃）

**① 模板格式（新页）**
```
{{高达OL基础性能 |名称=… |序号=… |装甲=4050 |最高速度=1238 …}}
{{高达OL武器模板 |武器名称=… |重量=200 |弹数=40/240 |威力=1050 |红锁距离=180 …}}
```
**② wikitable 格式（老页，占多数）**
```
{| class="wikitable"
|
!名称
!重量
…
!威力
!集弹性能
!射程距离
!锁定
|-
| rowspan="3" |[[文件:头炮1.png|无框]]
|60mm头部火神炮
<sup>红锁距离：180</sup>      ← ★红锁距离藏在名称格★
|240
|45/315
…
|}
```
机体数值则是无表头的键值网格：`|装甲 |4,125 |4,743 |推进器冷却力 |310 |356 |`（**两档值**）

## 3. 关键结论

- 1036 页里 **372 页是重定向**（`#REDIRECT`）、359 页模板格式、其余为老格式；
- **威力真值量级**：头炮 ~1000｜光束步枪 ~4650–6000｜近战光剑 ~5000–9500｜照射/蓄力 ~12000–27500
  ⇒ `../09-武器数值口径提案.md` 里我给的"机炮 200–350"**是错的**（该文已加"被推翻"横幅）；
- 两档值：cell 里形如 `1250 (1375)`，机体表另有 `*_2` 列 —— **取第一档为准，第二档备用**；
- 机体数值与 **#34 的面板参数一一对应**：装甲↔`MAX_HP`｜最高速度↔`MOVE`｜推进容量↔`BOOST_GAUGEMAX`｜
  **推进器冷却(回气)↔`BOOST_GAUGEHEAL`**｜载重量↔装备搭载量｜紧急返回性能↔`WARP_TIME` ⇒ 可与 `codex` **交叉校验**；
- 老格式页**没有机体序号**（259 台）⇒ 与武器ID 的桥接更难。
