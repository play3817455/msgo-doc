## 0. 先厘清：这 79 个文件到底是什么

| 问题 | 结论 |
|---|---|
| 清单来源 | `unpackdat/settings/download_list.csv`（表头 `#データ定義,ファイル名,`）**76 行** ＋ **3 张本地表**（不下发）＝ **79** |
| 它们是什么 | **服务端下发的游戏"数值/规则/配方"表**（CSV 方言：UTF-8 无 BOM、CRLF、数据行留尾逗号、`#` 行跳过） |
| ★ 不是它们 | 客户端本地 `unpackdat/settings/*.csv`（**62 张**）是另一批"**资源/UI/语音/地图**"表（表头是日文 + `#`）。两边**无同名文件**，只有**近亲**（例：本地 `bgm.csv` 里有「BGMパックID」↔ 服务端 `BGMPACKAGE`） |
| 3 张本地表 | `LVUP_MSMA`(id14)、`MSMA_MATERIAL`(id18)、`BGMPACKAGE`(id39) —— 只在客户端本地用，**不从服务端下** |
| 特殊一张 | `AUTOEXEC`(id0) = **服务端启动脚本** `autoexec_sv.cfg`，**不是 CSV**，无列定义（`server/autoexec_sv.cfg` 已是唯一"有真内容"的文件） |
| 什么时候下 | 30001 大厅认证通过后，由 `0xF86A` 泵**逐张**下发（N6）。★泵是**全有或全无**：任意一张解析失败 ⇒ **永久死锁** ⇒ 进不去大厅 |
| 分组依据 | `download_list.csv` 的**路径前缀**：`msma/ item/ growth/ develop/ mission/ command/ npc/ module/ gacha/ clan/ pilot/ reward/ banner/ player_navi/ season_class/ trend/ quest/ buff/` |

**一句话**：这 79 个文件 = **这款游戏的全部"配置数值"**（机体/武器/道具/任务/开发/奖励/赛季…）。客户端下载后填进各自的 `C***Table` 对象，战斗与大厅 UI 全从这些表取数。
