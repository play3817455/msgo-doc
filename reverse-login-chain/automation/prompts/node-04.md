## 3. 研究清单

1. **分发器全 8 case**：`sub_B03D30` 的 `switch`/二分树，逐个 case →
   `cmp eax,<id>` 位置 + case 体地址 + 字段读取序列（含目前未用的 3 个 ID：0x60E0/0xA103/0x8F36）。
2. **发送侧**：5 条 send（0x34A9/0x2C1A/0x8288/0x3B8F/0xA380）的函数地址、参数列表、
   报文构造细节（尤其 0x2C1A 的账号/UUID/mac_addr 从哪来、0x8288 的 last_world 从哪来）。
3. **字段规则**：NUL 变长串的读取函数（`sub_B02BA0`）与"游标须恰等于报文尾"的校验点
   （`sub_B41120` 期望序号检查的位置与失败路径 `0xB890FE`）。
4. **世界条目**：309B 线上格式逐字段（名称/ID/状态…）；`count ≤ 32` 的约束。
5. **select_r**：30B 体的字段（result/name/host/port/userid/otp）与 `sub_439030` 的落盘偏移
   （`app+1168`/`+1297`/`+1340`）。
6. **状态机**：`sub_A88920` state 13~19 每步做什么、超时/失败回退（→ 998 重登）。
