## 0. 一句话结论

进频道 = **客户端主动两步请求、服务端各答一步**，无任何服务端推送：

```
① C→S 0x3E0B send_channel_list_get（体空，2B）  ⇒  S→C 0xF11C = u32 count(1..32) + count×54B 频道条目
② C→S 0x2830 send_channel_list_select（u32 channel_id，6B）  ⇒  S→C 0xFB85 = result|channel_id|host|port|userid|pilot_id|otp
③ 客户端收到 0xFB85(result≥0) 后：sub_43BC70 主动断 30001、存 host/port/otp、app[1396]=3、
   注册 tick sub_43ADD0 ⇒ 下一帧 case4 连 30002（复用同一会话槽）
```

两条 recv 的**长度校验规则**均为「分段读取 + 游标恰到底 + 有界 NUL 串」，任一段越界/缺 NUL/游标≠尾 ⇒ 整条 `error(门序号,1)` 静默丢弃。

**长度校验规则**：
1. `count` 读失败（剩余 <4）⇒ `error(5,1)` 丢弃。
2. `count > 32`（`cmp ebx,20h; ja`）⇒ `error(5,1)` 丢弃（@`0xB86514/17`）。
3. 每条 `sub_B420E0` 内部逐字段做「剩余字节」检查，任一不足 ⇒ 该条失败 ⇒ `error(5,1)` 丢弃（@`0xB8655A`）。
4. 全部读完须「游标恰到底」：`cmp [var_2C44],[var_2C40]; jz`（@`0xB8656B`），否则 `error(5,1)` 丢弃。
5. 线长 = `4 + 54×count`；alloc 1924 = `4 + 32×60` ✓（60 = `sub_B41230` 内存步长）。

**内存/线偏移对照**（与 W07/W09 同款 padding 规律）：
- 线格式 **54B**；解析缓冲每槽 **60B**（`sub_B420E0` 写 54B + 6B padding，`sub_B41230` 步进 60）。
- `sub_43F1D0` 重建 app+1376 频道向量时**再压缩为 48B 元素**（只保留 `channelid/name/type/pilotlv_min/pilotlv_max/user_num_eff/user_num_zeon/user_conn`，并算 `total=eff+zeon`；`user_max/user_comeback` 不进向量）。⇒ 服务端只关心**线 54B**。

### 3.5 有界串读取器 `sub_B02BA0`（★两条串共用，服务端必须遵守）

```c
char sub_B02BA0(char* dst, u32* cursor, int limit) {
    n = min(cursor_end - cursor, limit);       // 剩余 vs 上限取小
    if (n < 0) return 0;
    p = memchr(cursor, 0, n);                  // 限内找 NUL
    if (!p) return 0;                          // ★找不到 NUL ⇒ 失败
    copy(dst, cursor, p - cursor + 1);         // 复制含 NUL
    *cursor = p + 1;                           // 游标停 NUL 之后
    return 1;
}
```
- **不要**用定长 129/41 填零 ✗（游标会 ≠ 尾 ⇒ 整条丢弃）；必须 **NUL 结尾**。

## 6. 对服务端落地的影响

1. **0xF11C 的 `count` 必须 ≥1 且 ≤32**，条目线长恰 54B；count=0 会让客户端频道向量为空 → 弹错误框。
2. **0xFB85 两条串必须 NUL 结尾、限内（host≤128 / otp≤40）**，不能定长填零；`result<0` 会让客户端弹「频道连接失败」并回选频道（不崩，但会把「没反应」误判成协议错）。
3. **channel_id 必须回显**请求值（`sub_43BC70` 用它查 app 频道向量定位条目）。
4. 客户端收到 0xFB85 后**主动断 30001 并连 30002**（复用同一会话槽 + access 握手 + Camellia 帧）⇒ 服务端无需「推送」任何进频道包。
5. 门序号证据补强总表 §0「接收门序号 = 发送通知索引 + 1」：`0x3E0B(send n=4)→0xF11C(recv n=5)`、`0x2830(send n=6)→0xFB85(recv n=7)`，两组均成立。
