## §0 一句话结论

**四条命令、一条链：`0x7421`（查）⇒`0x3C66`、`0x786D`（买）⇒`0x73F0`，买的「天数 × 价格」全部由服务端
`srv.chargepoint_price` 决定（客户端只报「买第几期」），扣的是 `core.pilot_meta.charge_point`（MB）。
客户端**完全不读 `result`**，只认 `remaining_days` 一格 —— 而 `0xFF` 是它在购买应答里写死的「失败」哨兵
（`sub_AFDDF0`），且 **只有购买应答会把它当失败**，查询应答会老老实实写成「255 天」**
⇒ 服务端必须：成功回真天数、**购买失败回 `0xFF`、查询失败回 `0`**。**

用户实测的原始症状（2026-09-22 10:49）：`[channel] unhandled 0x7421 len=2 未响应`
—— 没回包时客户端 `app+0x1BFFC` 停在 1（在途），月卡面板一直转圈。

## §2 客户端侧（本次反编译复核）

### 2.1 查询应答的应用器：`sub_AF8070`（`vt[0x18C]` → 实测指向它）

```c
int sub_AF8070(int a1 /*result，丢弃*/, char a2 /*remaining_days*/) {
  *(_BYTE  *)(dword_11E3EA8 + 114665) = a2;   /* app+0x1BFF9 = remaining_days */
  *(_DWORD *)(dword_11E3EA8 + 114668) = 2;    /* app+0x1BFFC = 2（状态机完成） */
}
```

- 本次复核：`xrefs_to 0xAF8070` 只有一处引用 —— `0xBAB9BA`（在包装器 `sub_BAB9B0` 里）。
- 包装器所在槽：`sub_BAB9B0` 在**两个** vtable 槽里都出现（`0xEEDCF8` = slot `0x18C`、`0xEEDCDC` = slot `0x170`），
  两个槽是同一个指针（重复项），所以「去向 = `vt[0x18C]`」与「`vt[0x170]` 也是它」并不矛盾。
- ★**没有 `-1` 分支**：这条路径**不认 `0xFF`**，回 `0xFF` 会被照抄成「剩余 255 天」。

### 2.2 购买应答的应用器：`sub_AFDDF0`（`vt[0x190]` → 实测指向它）

```c
char __cdecl sub_AFDDF0(int a1 /*result，丢弃*/, char a2 /*remaining_days*/) {
  if (a2 == -1) {                                  /* 0xFF ⇒ 失败 */
    v3 = sub_BC46A0(1006638179);                   /* 失败提示（资源 id） */
    ... sub_737F90(sub_4332B0(v3, 0, 0.0, 2, 0,0,0,0)); return;   /* 弹框 */
  }
  *(_BYTE  *)(dword_11E3EA8 + 114665) = a2;        /* app+0x1BFF9 = remaining_days */
  *(_DWORD *)(dword_11E3EA8 + 114668) = 2;         /* app+0x1BFFC = 2 */
}
```

- 本次复核：`xrefs_to 0xAFDDF0` 只有一处引用 —— `0xBAB9DA`（包装器 `sub_BAB9D0`）；
  `0xEEDCFC`（= slot `0x190`，vtable 基址 `0xEEDB6C`）里正是 `0x00BAB9D0` ✓。
- **`a1`（= 线上 `result`）被完全丢弃** ⇒ 服务端写 `result` 只为自己的日志/排障，客户端不看。
- `-1` 是按 **`char`** 比较的 ⇒ 线上那一格是 `u8`，`0xFF` 即 `-1` ✓。

### 2.3 购买请求的发送：`sub_A06C50`（`period_path` 是 1 基）

```c
if (a2) {
  if (!a1) {
    *(_DWORD *)(dword_11E3EA8 + 114668) = 1;   /* app+0x1BFFC = 1（在途） */
    sub_AFEE80(a2[368] + 1);                   /* 发 0x786D，period_path = 选中下标 + 1 */
    sub_AF2580(30102200);
    return (*(vt+656))(a2);
  }
}
```

- 本次复核 ✓（`0xA06C50`）。
- ⇒ **`0x786D` 的 `period_path` 是 1..3**，映射到 `srv.chargepoint_price` 的 `periodpath_ticket_{0,1,2}`：
  `period_path - 1` = 期段索引。**0 非法**（客户端自己不会发 0）。

### 2.4 状态机：`app+0x1BFFC`

| 值 | 含义 | 谁写的 |
|---|---|---|
| 0 | 空闲 | 初始 / 面板初始化 |
| 1 | **在途**（已发请求，等应答） | `sub_A06C50`@`0xA06C65`（买） |
| 2 | 完成（`app+0x1BFF9` 里已是剩余天数） | `sub_AF8070`（查）/ `sub_AFDDF0`（买） |

★**服务端在**任何**分支都必须回包**（连失败、连内部错误也要回）—— 不回不是"没反应"，是面板永久卡在 1。

## §3 服务端契约（本服实现，`serverv\internal\lounge\pilot_monthlypassport.go`）

| 情形 | `result` | `remaining_days` | 备注 |
|---|---|---|---|
| 查询成功（持有/从未买/已过期） | `0` | 真天数 `0..254` | **绝不回 `0xFF`**（§2.1） |
| 购买成功 | `0` | 延期后的真天数 | 再推一次 `0x02F6`（余额变了） |
| 购买失败（余额不足 / 期段未上架 / 越界 / 事务错） | 负错误码 | **`0xFF`** | 客户端据此弹失败框 |
| 查询侧读库失败 | `0` | `0` | 当作"未持有"，别让面板卡住 |

- `result` 里放的是负错误码（二补数下发 `u32`）；客户端不看，但日志可与 `error_code.csv` 对齐。
- 天数夹取：`ceil((expires_at - now)/1day)` 夹到 `0..254`；**255 保留给失败哨兵**，所以真天数上限是 254
  （`store.PassportRemainingDays`，有单测钉边界）。

## §4 落库（两张表 + 一张价目表）

### 4.1 `core.pilot_meta.charge_point`（迁移 0016）— MB 余额

- **per 机师**的标量，不是账号的（`0x063E` 选机师时下发、`0xE13A` 列表尾部带一格、`0x02F6` 推变更）。
- 线上 u32 ⇒ 列 `BIGINT` + `CHECK (charge_point BETWEEN 0 AND 4294967295)`。
- **默认 0；只在建号时播种**（`lounge.pilot.charge_point_seed`，本服缺省 `9999999`）。
  读路径（`0x063E`/`0xE13A`/`0x02F6`）**绝不写库** —— 否则"花光到 0"会被下一次读回血成种子值。

### 4.2 `game.pilot_monthlypassport`（迁移 0017）— 持有状态

- 主键语义 = `(world_id, pilot_id)`（唯一索引 `uq_game_pilot_monthlypassport_world_pilot`），**per 机师**。
- **存「到期时刻」而不是「剩余天数」**：`expires_at TIMESTAMPTZ`（`NULL` = 从未开通 ⇒ 下发 0 天）。
  剩余天数每次现算 ⇒ 跨天/重启/GM 改表都不会算错，也不用每天跑定时任务减 1。
- **续期 = 只增期**：`max(now(), 原到期) + N 天` ⇒ 提前续费不吃掉剩余时间。
- 扣费与延期**同一个事务**（`store.PayPilotMonthlyPassport`），扣款用
  `UPDATE … WHERE charge_point >= amount` 做原子守卫 ⇒ 并发下不会超扣。

### 4.3 `srv.chargepoint_price` — 期段价（买几天、花多少 MB）

- 六列 `periodpath_ticket_{0,1,2}_{days,bc}` 就是 `SC-0x9397` 里的期段字段（W22 §2：该回包由 state 8 的 `0x7CCB` 触发）。
  客户端**只拿到展示用的数字**，真正的买卖判定在服务端。
- **改这张表即热更**：服务端每条 `0x786D` 都重读（无缓存），下一条请求就按新价算，不用重启。
- `days = 0` = **该期不卖**（购买回失败、不扣费）⇒ 运营停售某一期不用改代码。
- 本服种子值（**自定，非原作数值**，原作数值无从考证）：`7 天 / 800 MB`、`30 天 / 3000 MB`、`90 天 / 8000 MB`。

## §5 MB 的三个出口（必须同源）

| 出口 | 时机 | 本服做法 |
|---|---|---|
| `0x063E pilot_select_r` 顶层 `+0x08` | 选机师 | 读 `core.pilot_meta.charge_point` |
