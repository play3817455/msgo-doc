## 0. 一句话结论

认证连接（`:30000`，类 `CGVOProtoAuth`，vtable `0xEED714`）是**收发对称的门控式协议对象**：

### 2.1 协议门控（`sub_B02C90`，收包必经）

```
sub_B02C90(this, n):                                   // n = 报文序号
  if (this[n+108] == 0) → cb(this, n, 2); return 0      // 该报文当前"不允许接收"
  rec = &this[48*n+128]
  if (qword@rec+16 != 0) {                              // 装了时间预算才校验
      sub_B02C00(rec);
      if (rec[0] > rec[1]) → cb(this, n, 3); return 0   // 超预算
      ++rec[0];
  }
  return 1
```

- `cb` = `vt[25]` = `nullsub_35`（空函数）⇒ 三种失败码（0=未知ID / 1=体长不符 / 2=门控关闭 / 3=超预算）**都只被静默吞掉**。
- `sub_B02F10`（✅ 本轮反编译确认）：
  ```
  v4 = (_BYTE*)this + 108;
  循环 16 次: *(v4-16)=1（即 this[92+i]）; *v4++=1（即 this[108+i]）
  ```

  ⇒ 两组门控位（send `+92..107` / recv `+108..123`）**一次性全置 1**，门控默认全开。

### 3.4 两种字符串约定（★必须区分）

| 约定 | 读取器 | 行为 | 适用 |
|---|---|---|---|
| **NUL 变长串** | `sub_B02BA0` / `sub_B02B40` | 在 `limit` 内 `memchr(0)`，游标停在 NUL+1；找不到 ⇒ 失败 | 顶层报文字段（`0xF24B`/`0x2C1A`/`0x1146`/`0x60E0` 的串） |

> ★ 服务端造包铁律：
> 1. 顶层变长字段一律 **NUL 结尾、首尾紧贴、报文尾无填充**（`p==end` 校验）。
